# M6 TUI

## 目标

进入交互模式时用全屏界面：上方是对话记录，下方是输入行，最底下一行状态栏。
用 `--tui` 显式开启；单轮模式（`li "问题"`）和管道用法不受影响。

## 不做

- 鼠标支持、可点击区域。
- 消息折叠/展开。
- 输入历史导航（上下箭头）、多行编辑。
- 主题配置。

## 接口

输出不再直接写终端，而是经过 `Ui` trait：

| 方法 | 语义 |
|---|---|
| `assistant(text)` | 模型回答的流式增量 |
| `assistant_end()` | 本条回答结束，另起一屏 |
| `tool(line)` | 一次工具调用或结果摘要 |
| `status(line)` | 进度、警告、中断 |

- `PlainUi`：保持原来直接写 stdout/stderr 的行为。
- `TuiUi`：把调用转成 `UiEvent`，发给渲染任务。
- `TuiApprover`：危险命令确认显示在状态栏，按 `y` 通过、`n`/`Esc` 拒绝。

## 行为

- 对话区按内容自动滚动到底部。
- 用户输入青色加粗，工具输出灰色，状态栏黄色。
- `Enter` 发送；`exit` 或 `quit` 退出；`Ctrl-C` 随时退出；输入框为空时 `Esc` 退出。
- 模型在后台任务里跑，界面不因生成而卡住。

## 验收

- 启动后能看到边框、对话区、输入区。
- 中英文输入都能回显，`Enter` 把内容发给模型。
- 模型回复逐字出现在对话区。
- 危险命令确认时状态栏出现 `[y/N]`。

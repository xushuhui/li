# 仓库规则逐层加载

## 目标

在 monorepo 的子目录里启动时，仓库根和每一级父目录的 `AGENTS.md` 都要生效，而不是只读最近的那一个。

## 做法

1. 从当前工作目录向上走，每一层查 `AGENTS.md`，存在就读。
2. 遇到含 `.git` 的目录（含它本身）停止，仓库外的文件不会混进来。
3. 按从外到内的顺序拼进系统提示，每段标注来源路径。
4. 空文件或只有空白字符的文件跳过。

## 验收

- 根、中间层、当前目录各有一份 `AGENTS.md` 时，三份内容都在系统提示里，顺序是从外到内。
- 仓库外（`.git` 的父目录）的 `AGENTS.md` 不出现。
- 只有根目录有时，行为与改动前一致。
- 空规则文件不产生空段。

## 不做

- 支持 `CLAUDE.md` 等其他文件名（D10 已否决）。
- 按子目录内容动态重载规则（只在启动时读一次）。
